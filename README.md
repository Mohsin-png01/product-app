Products App

A simple products app built with HTML, CSS and JavaScript.

Features

 Fetches products from API
 Search products by title
 Add/remove favourites
 Shows favourite count
 Loading and error states
 Mobile friendly

How it works

I used fetch and async/await to get the products from the API. The search filters the products by title as the user types. Favourites are stored in an array and the count updates when a product is added or removed.

Tech

HTML, CSS, JavaScript
